# نظام إدارة محل الحديد والعدة (MERN Stack)

نظام كامل لإدارة المخزون، المبيعات، المشتريات، والأرباح لمحل حدايد ومعدات وأدوات زراعية وبناء.

## المكونات

- **الباك إند**: Node.js + Express + MongoDB (Mongoose)
- **الفرونت إند**: React + Vite + Tailwind CSS + Recharts
- التوثيق بـ JWT، وصلاحيتين: **أدمن** (صاحب المحل) و **كاشير** (عامل بيع)

## المميزات

- إدارة المنتجات (كود بيتولد أوتوماتيك بترتيب الإضافة، صورة، اسم، فئة، وحدة، سعر شراء/بيع، رصيد افتتاحي)
- تسجيل المشتريات (بتزود المخزون تلقائي)
- تسجيل المبيعات (بتقلل المخزون تلقائي وتحسب الربح لحظيًا)
- شاشة مخزون حية بتوضح الأصناف اللي قربت تخلص
- لوحة تحكم بترحيب بالمستخدم ومؤشرات الشهر (مبيعات، أرباح، قيمة المخزون)
- صفحة تقارير بمخطط بياني لآخر 6 شهور
- بحث شامل من أعلى الصفحة (منتجات، مبيعات، مشتريات) + بحث في كل صفحة على حدة
- طباعة فاتورة لأي عملية بيع أو شراء، بلوجو واسم وتليفون المحل
- **صفحة إعدادات أدمن**: لوجو المحل، بيانات المحل، فئات المنتجات، حد التنبيه بنقص المخزون
- **صفحة إدارة المستخدمين**: إضافة كاشير جدد، تغيير الصلاحيات، إيقاف/تفعيل الحسابات

## طريقة التشغيل

### 1. الباك إند

```bash
cd backend
npm install
cp .env.example .env
# افتح .env واملأ القيم (خصوصًا MONGO_URI و JWT_SECRET)
npm run dev
```

السيرفر هيشتغل على `http://localhost:5000`.

لازم يكون عندك MongoDB شغال (محليًا أو عن طريق MongoDB Atlas مجانًا).

### 2. الفرونت إند

```bash
cd frontend
npm install
npm run dev
```

الموقع هيفتح على `http://localhost:5173`.

### 3. أول تشغيل

افتح المتصفح على `http://localhost:5173/setup` وسجّل بيانات صاحب المحل (الأدمن الأول). بعد كده أي حساب تاني بيتضاف من صفحة "المستخدمين" داخل النظام.

## خطوات لازمة قبل الاستخدام الفعلي (Production)

1. غيّر `JWT_SECRET` في `.env` لقيمة عشوائية قوية.
2. استخدم MongoDB Atlas أو سيرفر مستضاف بدل التشغيل المحلي.
3. ارفع الباك إند على خدمة زي Render أو Railway، والفرونت إند على Vercel أو Netlify.
4. فعّل HTTPS في أي بيئة إنتاج حقيقية.
5. اعمل نسخة احتياطية دورية لقاعدة البيانات.

## أفكار للمرحلة الجاية (لما السيستم يثبت)

- باركود للمنتجات
- كشف حساب موردين وعملاء (آجل)
- تسجيل المرتجعات
- تنبيهات واتساب عند نقص المخزون
- نسخة PWA للموبايل
